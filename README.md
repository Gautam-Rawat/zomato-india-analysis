# Zomato India - Restaurant Analysis

An end-to-end dataanalysis project explorin restaurant trends across Indian cities using zomato dataset.

## Tech Stack
- Python (pandas, numpy, matplotlib, seaborn)
- PostgreSql (coming soon)
- Power BI / Tableau (coming soon)

## Setup 
1. Clone this repo
2. Create virtual env: 'python -m venv venv && source venv/bin/activate
3. Install deps: 'pip install -r requirements.txt
4. Download fataset from and place in 'data/raw'
